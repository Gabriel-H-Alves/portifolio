# Portfólio — Gabriel Henrique

Landing page profissional minimalista, com fundo branco, responsiva e desenvolvida com HTML, CSS e JavaScript puro.

## Como executar
1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador.
3. Para desenvolvimento, você pode usar a extensão Live Server do VS Code.

## Personalizações importantes antes de publicar
- No `index.html`, substitua `SEU_EMAIL@exemplo.com` pelo seu e-mail profissional.
- Confira os links do GitHub e LinkedIn.
- Adicione links reais para os repositórios/demonstrações dos projetos quando estiverem públicos.
- Revise os textos de formação e tecnologias para refletirem exatamente sua experiência atual.

## Estrutura
- `index.html` — conteúdo e estrutura semântica.
- `style.css` — identidade visual, layout e responsividade.
- `script.js` — menu mobile e ano automático no rodapé.

Não utiliza frameworks ou dependências de instalação. A fonte é carregada pelo Google Fonts; sem internet, o navegador usa fontes alternativas.
